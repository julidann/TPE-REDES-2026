Paso 4: Port Forwarding (DNAT) y Pruebas Web/Sockets (Incisos h, i, j, k)

Para que desde afuera (y desde adentro usando la IP pública) puedan entrar al Server-Docker (10.13.0.3) a través de R2 (201.0.1.2), agreguen estas reglas en el Firewall de R2:

sh
# Reenvío de puertos (DNAT) para HTTP (80) y Sockets (15000 TCP y UDP)
iptables -t nat -A PREROUTING -d 201.0.1.2 -p tcp --dport 80 -j DNAT --to-destination 10.13.0.3:80
iptables -t nat -A PREROUTING -d 201.0.1.2 -p tcp --dport 15000 -j DNAT --to-destination 10.13.0.3:15000
iptables -t nat -A PREROUTING -d 201.0.1.2 -p udp --dport 15000 -j DNAT --to-destination 10.13.0.3:15000
# Permitir el pasaje de esos paquetes hacia el Server-Docker
iptables -A FORWARD -d 10.13.0.3 -p tcp --dport 80 -j ACCEPT
iptables -A FORWARD -d 10.13.0.3 -p tcp --dport 15000 -j ACCEPT
iptables -A FORWARD -d 10.13.0.3 -p udp --dport 15000 -j ACCEPT

(Nota para los incisos i y k: Si PC-1 accede a 201.0.1.2, el paquete entra a R2 por eth1 y vuelve a salir por eth1 hacia 10.13.0.3. Paso 5: Prueba de bloqueo en caliente con REJECT vs DROP (Inciso l)

Con la simulación corriendo, abran una terminal en R2 y ejecuten:

Con REJECT:
sh
iptables -I FORWARD 1 -p udp --dport 15000 -j REJECT
¿Qué pasa?: El cliente TCP sigue funcionando normal. El cliente UDP falla o se entera del rechazo inmediatamente porque R2 le devuelve un paquete ICMP Destination Unreachable (Type 3, Code 3: Port Unreachable).
Reemplazar por DROP:
sh
iptables -R FORWARD 1 -p udp --dport 15000 -j DROP
